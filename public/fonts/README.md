# GORISE webfonts

Font files in this directory are self-hosted WOFF2 subsets (Vietnamese and Latin) served by [Google Fonts](https://fonts.google.com/). They are covered by the accompanying SIL Open Font License files.

- **Baloo 2** (variable weights 600–800): [specimen](https://fonts.google.com/specimen/Baloo+2), [license](https://fonts.google.com/specimen/Baloo+2/license). CSS source: `https://fonts.googleapis.com/css2?family=Baloo+2:wght@600..800&display=swap`.
- **Be Vietnam Pro** (static weights 400, 500, 600, 700): [specimen](https://fonts.google.com/specimen/Be+Vietnam+Pro), [license](https://fonts.google.com/specimen/Be+Vietnam+Pro/license). CSS source: `https://fonts.googleapis.com/css2?family=Be+Vietnam+Pro:wght@400;500;600;700&display=swap`.

Each `@font-face` in `/styles.css` maps these files to the relevant Unicode subset. Keep both families' OFL texts when redistributing. Figma setup reference: [official remote MCP guide](https://help.figma.com/hc/en-us/articles/32132100833559-Guide-to-the-Figma-MCP-server) and [typography/styles write tools](https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/).
